# Tranter homepage widget update

`tranter-homepage-widget.html` is the updated Elementor HTML widget source based on the supplied homepage code.

Changes included:

- Feed/banner pills now normalize their category from the explicit class or item title and use distinct modern event, blog, news, offer, and insight treatments.
- Who We Are now uses a layered visual with a floating delivery-system panel above the existing image and status badge.
- Clients that trust us now includes the supplied banking, consumer, public-sector, pension, finance, and logistics logos in a mixed-sector marquee sequence.

The repository's existing `index.html` remains the separate ITGov event microsite and was not overwritten.
